# 3D Conditional Generative Adversarial Network with Embedded Metadata
This code contains a `Conditional Generative Adversarial Network` example in Python using `torch`. It is heavily based off of the code from this article [https://realpython.com/generative-adversarial-networks/](https://realpython.com/generative-adversarial-networks/) but adapted to use 3D statevectors, adaptive batch sizes, and 2 additional metadata string embeds.

- Requirements:
    - `torch`
    - `pandas`
- Optional:
    - `jupyter` and `notebook`
    - `matplotlib`
